باک‌یار — نسخه آماده PWA

فایل‌ها:
- index.html: برنامه اصلی
- manifest.json: تنظیمات نصب وب‌اپ
- sw.js: کش آفلاین پوسته برنامه
- icons/: آیکون‌های نصب

نصب و اجرا:
1) همه فایل‌ها را با همین ساختار روی یک هاست HTTPS قرار بده؛ یا برای تست از localhost استفاده کن.
2) آدرس index.html را در Chrome اندروید باز کن.
3) منوی سه‌نقطه > Install app یا Add to Home screen را بزن.

نکته:
- PWA از روی file:// به‌طور کامل قابل نصب نیست؛ HTTPS یا localhost لازم است.
- اطلاعات برنامه فعلاً همان سازوکار ذخیره‌سازی موجود در HTML را دنبال می‌کند. برای همگام‌سازی بین چند دستگاه، بک‌اند/دیتابیس جداگانه لازم است.
- پوسته برنامه قابلیت کش‌شدن دارد، اما فونت گوگل و سرویس‌های خارجی در اولین بار به اینترنت نیاز دارند.
